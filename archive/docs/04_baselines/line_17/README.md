# 04 — Line 17: Baseline Variant

**Revision note:** stats below are pooled across both directions
(section C); baseline is the *merged* variant from
[docs/03_variants/line_17](../../03_variants/line_17/README.md)
(direction_A: 0+1 merged, `n=487`; direction_B: reference unmerged,
`n=618`). See [docs/02_route_mapping](../../02_route_mapping/README.md)
for direction labels.

**Pooled (both directions): n=944 baseline blocks, mean end-to-end time
59.7 ± 9.6 min** — the smallest standard deviation (most consistent
trip duration) of any line except 97.

**Pooled weekday pattern:** Sun 1,622, Mon 1,408, Tue 1,770, Wed 1,429,
Thu 1,634, Fri 1,057, Sat 88 — line 17 has the sparsest Saturday
baseline volume of any line in scope.

`pipeline/pooled_analysis.py`, `pipeline/plot_baselines.py`,
