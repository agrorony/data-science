# 05 — Line 14: Baseline vs. Blocked/Special Variant (Control)

Method and headline finding: [docs/05_skip_comparison](../README.md).

**n=13 blocked vs n=1,739 baseline blocks (pooled directions); overall
median delta: −1.4 min.** All 10 hours with any blocked data are
flagged "thin" (<8 observations) — this is not a reliable estimate, it
reflects a handful of rare, essentially meaningless single-observation
route deviations (see
[docs/07's addendum](../../07_blockade_investigation/README.md) on why
control lines now have a nonzero "blocked" count at all under the new
>15-stop rule).

**Answer:** no meaningful conclusion can be drawn for line 14 at this
sample size — treat the small delta as noise, not evidence.
