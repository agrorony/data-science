# 05 — Line 9: Baseline vs. Blocked/Special Variant

Method and headline finding: [docs/05_skip_comparison](../README.md).

**n=93 blocked vs n=1,605 baseline blocks (pooled directions, after the
round-3 count>5 significance floor — see main README section B2);
overall median delta: −15.9 min — the largest time saving of any line.**
12 of 17 hours have fewer than 8 blocked observations (thin data), so
treat the hour-by-hour shape as suggestive; the pooled overall number is
better supported.

**Answer:** line 9's blocked/special variant costs no extra time — it
saves substantial time, consistent with
[docs/03_variants/line_9](../../03_variants/line_9/README.md)'s finding
that line 9's detour activity is concentrated on direction_B and
behaves like a shortcut/express pattern rather than a forced detour.
